A firm grip on every download.

Connect your daemon

Start vise --daemon, then configure its local API below. Right-click a link and choose Send to Vise.

Use http://127.0.0.1 or http://localhost with your daemon port. The /api/downloads suffix is optional.
Copy daemon.VISE_API_TOKEN from ~/.vise/config.toml, or the environment token used to start Vise.
