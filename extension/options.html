Vise

A firm grip on every download.

Connect your daemon

Start vise --daemon, then configure its local API below. Right-click a link and choose Send to Vise.

Use http://127.0.0.1 or http://localhost with your daemon port. The /api/downloads suffix is optional.
Copy daemon.VISE_API_TOKEN from ~/.vise/config.toml, or the environment token used to start Vise.
Forward request credentials (off by default) Only explicit sends use these settings. Credentials are saved in the daemon’s private plaintext journal. Cookie forwarding requires an identifiable tab store and partition; otherwise use “Send URL only to Vise”.
Grant requests only this scheme and host (all its ports and paths). Cookies permission is requested only when cookie forwarding is checked. Grants do not turn forwarding on.

Loading settings…

Settings stay in this browser’s local extension storage. The token is not encrypted; protect your browser profile. Only links you explicitly send are shared with your local Vise daemon. Captured cookies and referers are never stored here. Separate forwarding switches start off. No page content is read. Browser site grants and saved preferences remain until revoked.
